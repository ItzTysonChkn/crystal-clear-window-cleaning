# Crystal Clear Window Cleaning

**Website for Crystal Clear Window Cleaning — Denver, CO**

## To complete the upload:

1. Download `crystal-clear-window-cleaning.html` from Claude
2. Rename it to `index.html`  
3. Drag it into this repo via GitHub.com (click "Add file > Upload files")

Or via git:
```bash
git clone https://github.com/ItzTysonChkn/crystal-clear-window-cleaning.git
cd crystal-clear-window-cleaning
cp /path/to/crystal-clear-window-cleaning.html index.html
git add index.html
git commit -m "Add full Crystal Clear site"
git push origin New
```

## Enable GitHub Pages (free hosting)
Settings → Pages → Deploy from branch → New → / (root) → Save

Your site will be live at: https://ItzTysonChkn.github.io/crystal-clear-window-cleaning
